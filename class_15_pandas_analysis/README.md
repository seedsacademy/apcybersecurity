> **Mission Briefing:** In this class, you will put your network and security analysis skills into action by analyzing a real-world sized dataset of **2,000 security events** using Python and `pandas`. You will trace suspicious IPs, uncover brute-force password guessing, and correlate denied firewall records into a forensic timeline.
