## Multiple-Choice Exam Strategy: The AP Pacing Formula

$$\frac{80 \text{ minutes}}{60 \text{ questions}} \approx 1 \text{ minute and } 20 \text{ seconds per question}$$

### 4 Pillars of High-Scoring MCQ Performance:
1. **Annotate the Scenario:** Circle the *primary threat actor*, the *target asset*, and the *constraint* (e.g., "without adding operational latency").
2. **Beware of Partial Truths:** Distractors often state an accurate cybersecurity fact that does *not* answer the specific scenario question.
3. **Pacing Discipline:** If a question involves a complex firewall table or code snippet, do not get bogged down for 4 minutes. Eliminate 2 obvious distractors, flag the question in Bluebook, make an educated selection, and move forward.
4. **Never Leave a Question Blank:** AP exams have zero penalty for incorrect guesses!
